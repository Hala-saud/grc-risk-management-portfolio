GRC Risk Management Portfolio

Project Overview

This project demonstrates the practical application of Governance, Risk, and Compliance (GRC) concepts through a fictional financial company named Namaa Finance.

The project follows a structured workflow to identify information assets, assess cybersecurity risks, review security controls, identify gaps, and develop remediation plans.

Project Objectives

• Develop an information asset inventory.
• Identify and assess cybersecurity risks.
• Document security controls and control gaps.
• Create a risk treatment and remediation plan.
• Track supporting evidence and remediation progress.
• Present key risk and compliance information through an executive dashboard.

Project Deliverables

• Asset Inventory
• Risk Register
• Security Controls Register
• Gap Assessment
• Risk Treatment Plan
• Evidence Tracker
• Executive Dashboard

Tools

• Microsoft Excel
• Microsoft Word

Scope and Disclaimer

This is a fictional, educational portfolio project created to demonstrate foundational GRC skills. It does not represent an actual assessment, audit, or compliance certification of a real organization.

Skills Demonstrated

• Governance, Risk, and Compliance (GRC)
• Cybersecurity Risk Assessment
• Information Asset Management
• Security Control Mapping
• Gap Analysis
• Risk Treatment Planning
• Evidence Tracking
• Excel-based Reporting
